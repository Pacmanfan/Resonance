# Resonance 0.10.0 — first public release

**Firmware version:** 0.10.0 · **Licence:** GPL-3.0-or-later · **Board:** ESP32-2432S032C

Resonance is an open-source binaural meditation device: two tones, one per
ear, over Bluetooth headphones, with noise and sound files from a microSD
card and timed sessions, on a 3.2-inch touchscreen board. This is the first
published state of the project. The tag `v0.8.2` marks the earlier firmware
baseline in the history.

## What it does

- Binaural tone, primary 20–1000 Hz and beat 0.5–40 Hz, click-free changes, presets.
- White, pink and brown noise; WAV and MP3 playback from microSD; mixer and soft limiter.
- Bluetooth A2DP output with scan and connect on screen.
- Seven factory sessions, a timer, pause / resume / stop, end fade.
- Touchscreen interface (HOME, FREQ, SND, SESS, SET); settings kept across restarts.
- Implemented but **not yet verified by ear or eye**: phase offset and
  inversion, golden partials, exponential sweeps, user-built sessions, layer
  mixer with fades, breathing pacer, frequency sequences, Resonance Lab.

## Changed in 0.10.0

- The separate Setup boot mode, Wi-Fi and the web interface are removed; the
  device has one operating mode and no network function.
- Firmware image 1.72 MB → 1.07 MB; free heap at rest 72 kB → 98 kB.

Full history: [CHANGELOG.md](../../CHANGELOG.md).

## Building

```bash
python3 firmware/tools/host_tests.py     # 15 host test programs
cd firmware && pio run -t upload         # build and flash over USB (PlatformIO)
```

**No firmware binary is attached.** The MP3 decoder the firmware links
(Helix, RPSL licence) is not GPL-compatible, and that question is open; see
[THIRD_PARTY_LICENSES.md](../../THIRD_PARTY_LICENSES.md). Build from source.

## Enclosure

OpenSCAD sources, STL exports and previews for five revisions are in
[`hardware/`](../../hardware/README.md). Only version 1 is recorded as
printed; v3, v4 and v4 slim have not been printed.

## Known limitations

- The 0.9 features have not been listened to or looked at by a person.
- On 0.10.0 itself, sound and touch were not re-checked by a person, and
  memory during MP3 playback over Bluetooth was not re-measured.
- Bluetooth (SBC) only; no wired output; no battery level; a card inserted
  while running is seen after a restart; one recording at a time.
- Mindfield is a research concept only; nothing of it is in this release.
